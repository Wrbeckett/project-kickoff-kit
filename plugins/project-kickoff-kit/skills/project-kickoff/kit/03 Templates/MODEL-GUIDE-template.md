## Rules (part of WORKFLOW-RULES)
1. **Set the model before the first message** of a session or job, from this file (it's also on the session's brief and the cheat sheet).
2. **When a job misses the mark:** check the prompt and files first, then raise the effort one step, then move up one model. Log what happened in WORKFLOW-REVIEW.md.
3. **When a job is easy every time:** try a lower effort first, then a smaller model, for well-scoped work only.
4. **Sonnet always at Extra high or Max?** Use Opus at Medium instead; it usually costs about the same per job.
5. **Fable only for the hardest, longest jobs**, and only with the owner's OK where it uses paid usage credits.
6. **New models:** when Anthropic releases one, Lead reruns one go-to job on it and suggests updates at the next weekly review.
