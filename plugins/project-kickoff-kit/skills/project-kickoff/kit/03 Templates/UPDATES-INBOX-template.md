# <Project> updates inbox (for everyone who can't post in the Lead chat)

A chat belongs to one person's Claude account, so only the owner can post in "<Project> – Lead". Everyone else (team members, other sessions, scheduled runs) adds updates here. **Lead reads this file at the start of every run and every reply about status**, handles each line, then moves it to "Handled".

## How to add an update
- One line each, newest at the bottom: `<date, time> · <your name or session> · <update>`
- Use the brief's numbers where you can: "done 3, 5; 9 tomorrow; skip 12".
- Questions for the owner start with **ASK:**. Workflow ideas start with **IDEA:**.
- Don't edit or delete other people's lines.
