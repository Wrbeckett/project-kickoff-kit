# Setup levels: Solo, Standard, Team

Claude recommends one level in the blueprint (new project) or the audit report (existing project), and the owner picks. Start at the lowest level that fits; the weekly review suggests moving up a level when the project outgrows it.

| | **Solo** | **Standard** | **Team** |
|---|---|---|---|
| Fits | One person, one kind of work, a few weeks to a few months | One owner, several kinds of work or a longer project | Two or more people working on it |
| Sessions | One (it is the Lead) | Lead + only the work sessions needed (usually 1–4) | Lead + work sessions |
| Files | PROJECT-HANDOVER.md (with §13 "Usage and models" filled in instead of separate files), CHEAT-SHEET.md optional | PROJECT-HANDOVER.md, SESSION-BRIEF per session, WORKFLOW-RULES.md, WORKFLOW-REVIEW.md, CHEAT-SHEET.md, USAGE-PLAN.md, MODEL-GUIDE.md | Everything in Standard + UPDATES-INBOX.md + trackers where work passes between people or sessions + the shared-folder set (CHANGES.md, ASSETS.md, People/<name>/ folders, a shared-files-and-owners table with protected files, a project lead, version copies and a weekly backup snapshot; kit › 09 Shared folder) |
| PDFs | "<Project> - START HERE.pdf" (one page is fine) | START HERE + Session prompts | START HERE + Session prompts, shared with the team |
| Rhythm | No scheduled runs unless the owner asks; a short weekly check-in in the chat | Brief and reports only where needed; weekly review | Weekly review; brief or reports agreed with the team |
| Rules | The owner's never-do list + read-first, handoff, file safety, usage and model rules | All the rules the project needs | All the rules the project needs + the updates inbox |

**Someone joining?** The owner makes a handover pack (Prompt 11) and the joiner follows JOIN.md. A Solo or Standard project usually moves up to Team at that point.

**Moving up a level:** Lead lists what would be added, the owner says OK, Lead builds only the new parts and logs it in WORKFLOW-REVIEW.md (Solo projects: in the handover's §12 Next steps).

**Levels are a starting point.** Every level also gets PROJECT-CHOICES.md. Add or drop any file, session or report for one project ("change: …" to Lead, logged in PROJECT-CHOICES.md), or set your usual level in MY-DEFAULTS.md.
