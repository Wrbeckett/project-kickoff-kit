# <Project> <topic> tracker (shared: <session A> · <session B> · Lead)

Use a tracker only when work passes between sessions (e.g. content made by one session and published by another).

## How this works
- One row per item.
- **Who updates what:** <session A>: columns …; <session B>: columns …; Lead: the owner's updates + weekly sync.
- Re-read right before writing. Change only your columns. Never delete another session's rows; mark DONE or DROPPED with a date.
- **Waits on:** what must happen first (another item's number, a person, a decision). "What's next?" skips rows that are still waiting. Clear it when the wait is over.
- Status words: IDEA → PLANNED → NEEDED → IN PROGRESS → READY (owner approved) → HANDED OVER → DONE (or DROPPED).
- Rows not checked against the real source are marked VERIFY.
