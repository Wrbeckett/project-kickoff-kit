# Starter presets

A preset is a starting point for a common kind of project. At the start of a kickoff, Claude offers the closest one; its answers become **suggestions to confirm** in the interview (never decisions), so the interview is shorter. Everything in a preset can be changed, and the owner's choices go in PROJECT-CHOICES.md.

| Preset | For |
|---|---|
| Event.md | A conference, gala, workshop, speaker series, launch party |
| Course.md | A course, workshop series, training program or curriculum update |
| Website.md | A new or redone website, online store or landing page |
| Client job.md | Work for a client: design, consulting, a build, a campaign |
| Research.md | A research question, report, grant, review or feasibility study |

Each preset also lists **plugins that pair well**. Claude suggests them as options only; the setup never depends on them.

No good match? Claude runs the normal interview. To add a preset, copy one of these and follow MAINTAINING.md.
