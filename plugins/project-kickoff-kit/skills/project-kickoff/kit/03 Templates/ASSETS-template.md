# <Project> assets: which version is current

One row per asset. Exactly one version of each is **CURRENT**. When a new version is approved, its owner marks it CURRENT, marks the old one RETIRED (the file moves to Archive; nothing is deleted) and adds a line to CHANGES.md.

| Asset | Current file | Owner | Approved (who, date) | Retired versions |
|---|---|---|---|---|
| <e.g. Logo> | 04 Assets/<file> | <name> | <name, date> | <older files, now in Archive> |
