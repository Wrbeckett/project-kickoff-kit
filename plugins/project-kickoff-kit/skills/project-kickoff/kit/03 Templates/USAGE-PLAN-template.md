## Efficiency rules (part of WORKFLOW-RULES)
1. **Start lean.** Add a report or scheduled run only when there's a real need; after two weeks the owner says which reports they read, and the rest are shortened or turned off.
2. **Heavy work early in the usage week** (the days right after the reset), never the day before the reset, and not on the owner's heavy days.
3. **Spread scheduled runs out.** Don't stack several at the same time or right after each other.
4. **Stop early when there's nothing new.** A run that finds no changes writes one line and ends, with no PDF.
5. **Read only what the job needs.** Keep the handover short, trim briefs weekly (ARCHIVE-LOG.md), and don't re-read big files that haven't changed.
6. **Build once, reuse.** Keep scripts and templates in the project folder, so runs fill in data instead of rebuilding from scratch.
7. **One job, one place.** Never run the same job in two chats; batch small requests into one message.
8. **Fresh chats on time.** Long chats cost more per message; start a fresh one when a chat gets long or slow.
9. **Right-size the model.** Each session and scheduled run uses the model and effort in MODEL-GUIDE.md: Haiku or Sonnet and lower effort for routine checks and reports, Opus for judgment work, Fable only with the owner's OK. To save usage, lower the effort before you drop to a smaller model.
10. **Check the pace weekly.** The owner sends a Settings › Usage screenshot (or Lead asks for one) for the weekly review.
