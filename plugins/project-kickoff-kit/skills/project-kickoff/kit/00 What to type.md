# What to type: every prompt on one sheet

Type these in a Claude chat (with the kit plugin installed, or the kit folder connected). Short words work: Claude knows the rest. **Lead** = your project's main chat. Full versions are in **04 Prompts to copy** (the number in the last column).

## Start
| You want to… | Type this | Where | # |
|---|---|---|---|
| Start a new project | **start a new project** | A new chat inside a new Claude Project, project folder connected | 1 |
| Organize a project that's already going | **audit this project** | A new chat in that project's Claude Project | 2 |
| Take over a project someone started for you | **take over this project** | A new chat in your own Claude Project, with their handover pack in the folder | 13 |
| Join a teammate's project | **join this project** | A new chat in your own Claude Project, shared folder connected | 12 |
| Open another work session | the prompt from your **Session prompts PDF** | A new chat in the project | 3 |
| Check the setup works (after building) | **fresh chat test** | A new chat in the project | 19 |
| Save your own settings for every project (plan, laptop work window, how you like updates) | **set up my defaults** | Any chat, with a folder of your own connected | 25 |

## Every day
| You want to… | Type this | Where | # |
|---|---|---|---|
| Know what to do next | **what's next?** | Any project chat | 18 |
| Give an update | **done 3, 5; 9 tomorrow; skip 12** | Lead (teammates: a line in UPDATES-INBOX.md) | 6 |
| Share an idea about how things run | **workflow idea: …** | Lead | 6 |
| Pick the right model for a job | **which model for this job: …?** | Any project chat | 8 |
| Check nothing is stuck or out of date | **health check** | Any session | 5 |
| Replace a chat that got long or forgetful | **update the handover for a fresh start**, then in a new chat: **this replaces the old <session> chat** | The old chat, then a new one | 4 |

## Change and grow
| You want to… | Type this | Where | # |
|---|---|---|---|
| Change how the project works | **change: …** (e.g. "change: no morning brief") | Lead | 10 |
| Undo one of those changes | **undo change <number>** | Lead | 10 |
| Add something new to the project | **add to this project: …** | Lead | 20 |
| Add a person and their role | **add a collaborator: <name>** | Lead | 21 |
| Change someone's role, or remove them | **change <name>'s role** · **remove <name> from this project** | Lead | 22 |
| Change the project lead | **change project lead to <name>** | Lead | 17 |
| Back up and tidy the files you already have | **organize my files** | Lead | 23 |
| Put the files back where they were | **undo the file moves** | Lead | 23 |
| Get your own dashboard | **make my dashboard** (later: **change my dashboard: …**) | Lead (collaborators: their own project chat) | 24 |
| Bring the project up to the latest kit | **upgrade this project to the latest kit** | Lead | 9 |

## When something's wrong
| You want to… | Type this | Where | # |
|---|---|---|---|
| Undo a change to a shared file | **restore <file> to <when>** | Any project chat | 16 |
| Fix tasks that didn't run, or move them to the right computer | **check the home computer setup** | Lead, on the computer that stays on | 14 |
| Anything else | describe what you expected and what happened | Lead (and see **00 Something's not working**) | |

## Hand over and finish
| You want to… | Type this | Where | # |
|---|---|---|---|
| Hand the project to someone | **hand this project to <name>** (then **zip it for <name> with a READ ME FIRST**) | Lead, or a new chat in the Claude Project where the work lives | 11 |
| Finish a project | **close this project** | Lead | 15 |
| Pause it for a while | **pause this project** | Lead | 15 |

**Tips:** Nothing is built, sent, bought or deleted without your OK. Start new sessions and scheduled tasks on the computer that stays on. Not sure? Ask Lead.
