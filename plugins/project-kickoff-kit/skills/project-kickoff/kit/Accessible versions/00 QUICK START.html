Quick start: run a project with Claude

One page. Everything else in the kit is there for when you need it.

Once (15 min)

  1. Get Claude: a paid plan (Pro or higher) and the Claude desktop app on the computer that stays on: your home computer (Mac or PC).
  2. Add the kit: install the Project Kickoff Kit plugin (see the kit's GitHub page), or connect the kit folder someone shared with you.
  3. Stop the home computer sleeping while it's plugged in (START HERE › "Your home computer" shows where). On a laptop, Claude will set a work window instead.

Each project (10 min, then answer Claude's questions)

  1. Make a folder for the project (Dropbox, Google Drive, iCloud or your computer).
  2. In the Claude app: Projects › New project, same name. Start a chat inside it.
  3. Click + › Add folder and pick the project folder.
  4. Click the model name next to the send button and pick Opus, Medium effort.
  5. Type what you want:

  1. Answer Claude's questions. "I don't know yet" is fine. Nothing gets built, sent, bought or deleted without your OK.
  2. Open the START HERE PDF Claude makes for your project. Your first chat is now the Lead: give it your updates ("done 3, 5").

Good to know

  • Want something different? Tell Lead "change: …". Everything in the kit can be changed.
  • From your phone: you can post updates in your Lead chat with the Claude mobile app. Start new sessions and scheduled tasks on the home computer.
