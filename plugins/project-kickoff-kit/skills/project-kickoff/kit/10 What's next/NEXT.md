# NEXT.md: instructions for Claude ("what's next?")

The person asked **"what's next?"** (or "what should I do now?", "where was I?", Prompt 18). Give them **one clear next step**, not a report. Read only; change nothing.

**Finding the kit:** see "Finding the kit" in README.md (plugin, connected kit folder, or the kit's GitHub page).

## Read (only what you need, in this order)
1. Shared-folder projects: the new lines in 00 Admin/CHANGES.md since your last run.
2. PROJECT-HANDOVER.md: §3 Current status, §10 Owner's open tasks, §12 Next steps (Solo: also §13).
3. This person's brief (or MEMBER file), and UPDATES-INBOX.md lines waiting for them.
4. Trackers: rows that are theirs and not DONE, with their **Waits on** column.
No handover yet? The project isn't set up: the next step is "start a new project" (or "audit this project" if work already exists). Say so and stop.

## Pick the step
- **Skip anything blocked:** a row or task whose "Waits on" isn't done yet, or a decision still waiting for someone. Mention a blocker only if it's the reason nothing else can move.
- **Prefer, in order:** something overdue or due today → a decision someone is waiting on from this person → the first item in §12 Next steps → the oldest open task that isn't blocked.
- **An idea or request keeps coming up** (in UPDATES-INBOX, the ideas log or the owner's messages) **but has no home in the setup?** Suggest "add to this project: …" (or "add a collaborator" if it needs a person).
- **Nothing open?** Suggest the weekly review, a "what could go wrong" check of the next phase, or "close this project" if the goal is met.

## Answer (5 lines at most)
1. **Next:** what to do, in one line, with the file or tool name.
2. **Where:** which chat or session, and the model and effort (MODEL-GUIDE.md). "Here" if this chat is right.
3. **Time:** rough minutes.
4. **Then:** up to two optional follow-ups.
5. One line if something important is blocked or overdue, with who it waits on.
Offer to start the step now. Don't start it without a yes.
