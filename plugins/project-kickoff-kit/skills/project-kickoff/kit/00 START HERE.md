# Project Kickoff Kit: Start Here

**In a hurry?** Open **00 QUICK START.pdf** (one page). **Stuck?** Open **00 Something's not working.pdf**.

**What this is:** a ready-made way to run any project with Claude, so the work stays organized, nothing gets lost between chats, and you always know what to do next. It works for a brand-new project or one that's already under way. It works for any kind of project: a website, a product, a course, an event, a client build, a research job.

**What you get out of it:**
- A clear folder structure for the project, with a place for everything.
- A short "handover" file that any Claude chat reads first, so it never starts from zero.
- One or more **sessions** (separate Claude chats), each with its own job, and one **lead session** that keeps them in step.
- A recommended **Claude model and effort** for each session and scheduled job, so hard work gets the smartest model and routine work doesn't use up your weekly limit.
- A morning brief, weekly reports and a weekly review, if the project needs them.
- Plain-language instructions and PDFs for you and anyone on your team, plus screen-reader-friendly copies in **Accessible versions**.

**Claude never guesses.** Whenever something isn't clear, it asks you. You make every decision; Claude does the setup and the legwork.

## What you need

1. A Claude account with the **Claude desktop app** (Mac or Windows). Projects, folders and scheduled tasks work best there.
2. A place for the project's files: a folder in Dropbox, Google Drive, iCloud or on your computer.
3. Optional: the **project-kickoff skill**. Add it once and Claude knows this process in every chat (see "Adding the skill" below).
4. **One home computer** (Mac or PC) that stays on with the Claude app open, where you start the project and its scheduled tasks. See "Your home computer" below.

## Your home computer (read this before anything runs on its own)
Pick **one home computer** for each project: the Mac or PC that stays on, where you start the project's chats and scheduled tasks. A desktop (a Mac mini, an iMac, a tower PC) is best. A laptop works only if it stays plugged in and awake.

**Why it matters:** a scheduled task that uses your files runs on the computer it was made on. If you set one up on your laptop and then close the lid, the task can't run, even if your desktop is on.

**For anything to run while you're away, the home computer needs:**
- **On and awake.** Turn off automatic sleep while plugged in:
  - **Mac:** System Settings › Energy (desktops) or Battery › Options (laptops) › turn on "Prevent automatic sleeping…" (wording varies by macOS version). The screen can still turn off.
  - **Windows:** Settings › System › Power & battery (or Power) › Screen and sleep › "When plugged in, put my device to sleep after": **Never**. The screen can still turn off.
- **Online** (Wi-Fi or cable).
- **The Claude desktop app open.** It can sit minimized in the background, but not quit. If it updates or restarts, reopen it.
- **The project folders still connected and synced** (Dropbox, Google Drive or iCloud running on that computer).
- **Each scheduled task's approval setting checked:** a run that has to stop and ask you stops when nobody is there. Claude tells you which setting each task got.

**Using a laptop? Set a work window instead.** Pick a regular time the laptop can stay open, plugged in and awake with the Claude app running, e.g. weeknights 8–10 pm or Sunday mornings. Claude then:
- schedules every task that needs your files **inside that window**, spaced out;
- sends you a **reminder** before it starts ("Plug in your laptop and leave Claude open: 3 tasks run from 8:15"), as a phone notification (Claude mobile app) or email, your choice;
- sends a **"done, you can close it"** message when the last task finishes;
- catches up next time if a window was missed (each task checks what it missed).

Outside the window, close the laptop whenever you like. Cloud-only jobs still run.

**Working from another computer?** Chat from anywhere (laptop, phone, browser), but **create scheduled tasks and start new sessions on the home computer**. If something was set up on the wrong computer, ask the Lead session with **Prompt 14** to move it.

**Jobs that don't touch your files** (a web check, a reminder) can run in the cloud and don't need any computer on.

## How it works in 5 steps

1. **Make the project folder.** Using the kit plugin, that's all. Using the shared kit folder, also copy one file into it (KICKOFF.md for new, AUDIT.md for existing).
2. **Make a Claude Project** with the same name, and connect the folder to a chat (the + menu › Add folder).
3. **Paste one prompt** from "04 Prompts to copy". Claude reads the file and starts.
4. **Answer Claude's questions.** If your project is an event, a course, a website, a client job or research, Claude offers a **starter preset** so there's less to answer. Claude shows the plan a section at a time, checks what could go wrong, and after building asks you for a 2-minute fresh chat test. New project: an interview. Existing project: an audit, then questions about anything unclear. Either way Claude asks which Claude plan you have and how much of your weekly usage this project may use.
5. **Claude builds the workflow** at the size the project needs (Solo, Standard or Team): folders, handover, session briefs, trackers, a "Start here" PDF for this project, and the prompts to open each extra session, with the model to pick for each. You approve each step.

## Adding the skill (optional, once)

If you got the skill as a card in a Claude chat, click **Save**. If someone shared the kit folder with you: open a Claude chat, connect the kit folder, and paste: "Read 05 Skill/SKILL.md and propose it as a skill for me." Then click Save on the card that appears. After that you can just say **"start a new project"** or **"audit this project"** in any chat.

## The habits that make it work

- **One kind of work per session.** The lead session knows who does what.
- **Every session reads the handover first** and updates it after every finished task.
- **Give your updates to the lead session.** It passes them on. Team members add theirs to the project's UPDATES-INBOX.md.
- **Nothing changes without your OK.** Money, posting, emails, deleting and deploying always wait for you.
- **Start things on the home computer.** New sessions and scheduled tasks go on the computer that stays on.
- **Stay inside your usage.** Claude plans the sessions, reports and scheduled tasks to fit the share of your weekly Claude usage you give the project, puts heavy jobs early in the week, and the weekly review checks the pace, so you don't run out mid-week.
- **Right model for the job.** Each session has a recommended model and effort: Opus for thinking work, Sonnet for clear routine work, Haiku for quick checks. Pick it before you start (click the model name next to the send button). See **06 Models and sessions cheat sheet.pdf**.
- **Not sure what to do?** Ask any project chat **"what's next?"** for one clear next step.
- **Weekly review:** Claude checks what's working, suggests tools, fixes and model changes, and you choose.

## Make it yours
Everything in this kit is a starting point. Three ways to change it:
- **For all your projects:** copy **MY-DEFAULTS-template.md** to a folder of your own, rename it **MY-DEFAULTS.md** and fill it in (your plan, setup level, models, words you prefer, things you always skip). Connect that folder when you start a project, and Claude starts from it. Keep it out of shared folders: it's yours.
- **For one project:** tell its Lead session **"change: …"** (Prompt 10), e.g. "change: no morning brief". Lead updates every file at once and records it in the project's PROJECT-CHOICES.md, so reviews and upgrades never undo it. "undo change 3" reverses it.
- **For the kit itself:** edit its files, or log the idea in KIT-FEEDBACK.md; MAINTAINING.md lists which files to update.

## From your phone
You can read and post in your Lead chat from the Claude mobile app ("done 3, 5", questions, ideas). Start new sessions and scheduled tasks on the home computer.

## When a project ends
In the Lead chat, type **close this project** (Prompt 15). Claude turns off its scheduled tasks so they stop using your usage, writes a final summary, archives the drafts and notes lessons for next time. **pause this project** keeps everything and just stops the runs.

## When the kit changes
Open the project's Lead session with the kit available (plugin installed, or this kit folder connected), and paste **Prompt 9**. Claude lists only the new changes that would help that project, and you choose. Found a problem with the kit itself? Tell any session "kit feedback: …" and it goes into KIT-FEEDBACK.md.

## Sharing with your team

For a project several people work on, read **09 Shared folder › Working from a shared folder.pdf**: one shared project folder, one owner per shared file, a change log and a list of current assets, so everyone's Claude works from the latest information.

Share the whole "Project Kickoff Kit" folder. Each person needs their own Claude account. They start with this PDF. For a shared project, share the project folder and the Claude Project with them too. Each person runs their own sessions. Only you can post in your Lead chat, so everyone else adds their updates to the project's **UPDATES-INBOX.md** file, one line each; the Lead session reads it every time it runs.
