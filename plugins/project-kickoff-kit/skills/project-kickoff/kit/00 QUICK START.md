# Quick start: run a project with Claude

One page. Everything else in the kit is there for when you need it.

## Once (15 min)
1. **Get Claude:** a paid plan (Pro or higher) and the **Claude desktop app** on the computer that stays on: your **home computer** (Mac or PC).
2. **Add the kit:** in the Claude desktop app, **Plugins** (left sidebar) › **Add** (top right) › **Add marketplace** › **Add from a repository** › type **Wrbeckett/project-kickoff-kit** › **Sync**, then click **Project kickoff kit** › **Add**. Or connect the kit folder someone shared with you. Can't install the plugin? On the kit's GitHub page (github.com/Wrbeckett/project-kickoff-kit) click the green **Code** button › **Download ZIP**, unzip it, and connect that folder in your chat (**+ › Add folder**). The kit works the same way.
3. **Stop the home computer sleeping while it's plugged in** (START HERE › "Your home computer" shows where). On a laptop, Claude will set a **work window** instead.

## Each project (10 min, then answer Claude's questions)
1. **Make a folder** for the project (Dropbox, Google Drive, iCloud or your computer).
2. **In the Claude app:** Projects › New project, same name. Start a chat inside it.
3. Click **+ › Add folder** and pick the project folder.
4. Click the model name next to the send button and pick **Opus**, **Medium** effort.
5. **Type what you want:**

| You want to… | Type |
|---|---|
| Start something new | **start a new project** |
| Organize a project that's already going | **audit this project** |
| Take over a project someone started for you (you have their handover pack) | **take over this project** |
| Join a teammate's project | **join this project** |
| Hand a project to someone | **hand this project to <name>** |
| Wrap up a finished project | **close this project** |
| Not sure what to do next | **what's next?** |
| Undo a change to a shared file | **restore <file> to <when>** |
| Add something new to the project | **add to this project: …** |
| Add a person and their role | **add a collaborator: <name>** |
| Back up and tidy your existing files | **organize my files** |
| See what matters to you at a glance | **make my dashboard** |

6. **Answer Claude's questions.** New to Claude? Say so: it goes slower and explains as it goes. Say yes when it offers to save your defaults and to back up your existing files. "I don't know yet" is fine. Nothing gets built, sent, bought or deleted without your OK.
7. **Open the START HERE PDF** Claude makes for your project. Your first chat is now the **Lead**: give it your updates ("done 3, 5").

## Good to know
- **Want something different?** Tell Lead "change: …". Everything in the kit can be changed.
- **From your phone:** you can post updates in your Lead chat with the Claude mobile app. Start new sessions and scheduled tasks on the home computer.
- **Every prompt on one sheet:** **00 What to type**.
- **Stuck?** Open **00 Something's not working**.
