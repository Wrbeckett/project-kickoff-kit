# Project Kickoff Kit

**Run any project with Claude, from kickoff to close.** Claude interviews you, builds a simple, organized setup (folders, a handover file every chat reads first, sessions with clear jobs, the right Claude model for each job, a usage plan, weekly reviews), and asks before it changes anything. Works for websites, products, courses, events, client work and research.

**New here?** Read the one-page [Quick start (PDF)](plugins/project-kickoff-kit/skills/project-kickoff/kit/00%20QUICK%20START.pdf). **Stuck?** [Something's not working (PDF)](plugins/project-kickoff-kit/skills/project-kickoff/kit/00%20Something%27s%20not%20working.pdf).

## Get started (about 15 minutes, once)

1. **Claude:** a paid plan (Pro or higher) and the **Claude desktop app** (Mac or Windows) on your **home computer**, the one that stays on.
2. **Add the kit as a plugin.** In the Claude desktop app: **Plugins** (left sidebar) › **Add** (top right) › **Add marketplace** › **Add from a repository** › type **`Wrbeckett/project-kickoff-kit`** › **Sync**, then click **Project kickoff kit** › **Add**. Claude shows a reminder to add only marketplaces you trust; that's normal. No GitHub account needed.
   - Can't install the plugin? On the kit's GitHub page (github.com/Wrbeckett/project-kickoff-kit) click the green **Code** button › **Download ZIP**, unzip it, and connect that folder in your chat (**+ › Add folder**). The kit works the same way.
   - Claude Code: `/plugin marketplace add Wrbeckett/project-kickoff-kit`, then `/plugin install project-kickoff-kit@project-kickoff-kit`.
3. **Keep the home computer awake while plugged in** (or let Claude set a work window if it's a laptop): see [START HERE](plugins/project-kickoff-kit/skills/project-kickoff/kit/00%20START%20HERE.pdf), "Your home computer".
4. *Optional:* copy [MY-DEFAULTS-template.md](plugins/project-kickoff-kit/skills/project-kickoff/kit/MY-DEFAULTS-template.md) to a folder of your own, fill it in, and connect that folder when you start a project.

## Each project

1. Make a folder for the project (Dropbox, Google Drive, iCloud or your computer).
2. In the Claude app: **Projects › New project**, same name; start a chat inside it; **+ › Add folder** › your project folder; pick **Opus**, **Medium** effort.
3. Type what you want:

| You want to… | Type |
|---|---|
| Start something new | **start a new project** |
| Organize a project that's already going | **audit this project** |
| Take over a project someone started for you (with their handover pack) | **take over this project** |
| Join a teammate's project | **join this project** |
| Hand a project to someone | **hand this project to &lt;name&gt;** |
| Not sure what to do next | **what's next?** |
| Wrap up a finished project | **close this project** |
| Undo a change to a shared file | **restore &lt;file&gt; to &lt;when&gt;** |

4. Answer Claude's questions. Nothing is built, sent, bought or deleted without your OK.

## Updates

New versions are published here; see the [changelog](plugins/project-kickoff-kit/skills/project-kickoff/kit/CHANGELOG.md). For a project you set up on an older version, type **Prompt 9** ("upgrade this project to the latest Project Kickoff Kit") in its Lead chat: Claude lists only the changes that would help, and you choose.

## Your files stay yours

The kit only holds instructions and templates. Your project's files live in your own folder, your Claude chats stay in your account, and nothing is shared unless you share it.
